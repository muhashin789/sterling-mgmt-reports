# Sterling Styles — Management reports (GitHub Pages)

Upload the whole folder to a GitHub repository and switch on Pages (Settings → Pages → Deploy from branch → main / root).

- `index.html` — home page with both reports
- `merchandising-kpi.html` — Merchandising KPI (Weekly Review v10 — TARGET & KMART order status 26-Oct) with HTML / PDF / PPTX downloads
- `target-kpi.html` — Target Australia KPI, File 36–38 (18 views, synced filters) with HTML / PDF / PPTX downloads
- `kmart-kpi.html` — Kmart Australia KPI, File 001–002 (18 views, synced filters) with HTML download
- `revenue.html` — Revenue & CM Earned (management dashboard, Buyer KPI, Manpower, Finishing, Line × Style, Buyer Ranking) with HTML / PDF / PPTX / Excel downloads, incl. the buyer ranking formula Excel

Revenue data 01 Jan – 24 Oct 2026. Public site: anyone with the link can open it.
